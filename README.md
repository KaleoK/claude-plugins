# KaleoK Claude Plugins

A collection of Claude Code plugins.

## Install

```
/plugin marketplace add KaleoK/claude-plugins
```

## Plugins

### task-management

Flat-file task management for Obsidian with:
- Daily/weekly views (Today, This Week, Next Week)
- Inline priority system with color-coded indicators
- Auto-archiving of completed tasks
- Recurring task support
- Cross-device sync via iCloud

```
/plugin install task-management
```
